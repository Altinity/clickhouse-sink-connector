# Post-merge build verification — 2.10.1 line

This file exists to give CI a commit to build so that a container image is
produced from the current `develop` head, which now carries the eight fixes
merged as #1413-#1420.

It documents what that image is expected to contain, so the artifact can be
matched back to the changes it verifies.

## Fixes included at this head

| PR | Issue | Defect |
|---|---|---|
| #1413 | #1096 | `/metrics` served with no `Content-Type`; Prometheus 3.x rejects the scrape |
| #1414 | #385  | INT8 (`Byte`) hard-cast to `Integer` fails every TINYINT batch |
| #1415 | #749  | ARRAY binding hard-casts to `ArrayList`, breaking every other `List` type |
| #1416 | #1379 | Initial snapshot never finishes: NPE on every unparseable record |
| #1417 | #1262 | MySQL `DOUBLE` auto-created as `Float32`, silently truncating precision |
| #1418 | #1231 | PostgreSQL `infinity` / `-infinity` `timestamptz` stored as empty string |
| #1419 | #1285 | Batch containing a missing ClickHouse table silently dropped, offset advances |
| #1420 | #1213 | `_version` stores UInt64 max without GTID, permanently winning RMT dedup |

Four of the eight are silent-data-loss or silent-corruption defects: #1379,
#1285, #1262 and #1213 all produce wrong or missing data with no error raised.

## Regression coverage added alongside them

Container-backed integration tests, each driving a live source database
through Debezium into ClickHouse:

- `UnparseableRecordProgressIT` — #1379
- `AutoCreateDoubleColumnPrecisionIT` — #1262
- `PostgresInfinityTimestampIT` — #1231

Unit-level coverage: `ClickHouseBatchWriterMissingTableTest` (#1285),
`VersionFallbackWithoutGtidTest` (#1213), `ClickHouseDataTypeMapperInt8Test`
(#385), `ClickHouseDataTypeMapperArrayTest` (#749),
`ClickHouseDataTypeMapperFloat64Test` (#1262), `MetricsContentTypeTest`
(#1096), `NullParsedRecordSkipTest` (#1379).

Every one of these was verified failing-first: the production change was
reverted, the test was run and observed to fail with the reported symptom,
then the change was restored and the test observed to pass.
