# Alternative-closure corpus.
#
# One valid MySQL statement per line. Every line is fed to the shipped
# debezium MySQL parser and must parse. The point is the PARSE TREE, not the
# translation: each group of statements exists to enter a grammar alternative
# that no other corpus statement reaches, so the coverage meter in
# GrammarAlternativeSweepTest can prove the surface is exercised.
#
# A line is added only when a statement is real MySQL syntax. An alternative
# that no real statement can reach is listed in that test's UNREACHABLE set
# with the reason, never faked with a statement a server would reject.
